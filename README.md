# Artificial Intelligence Internship – Student Performance Prediction

## 📌 Project Overview

This project was developed as part of the **CSE7000 – Internship on Artificial Intelligence** at Presidency University, Bengaluru.

The project, titled **“Student Performance Prediction Using Machine Learning,”** focuses on predicting student academic performance using factors such as attendance, study hours, assignment scores, previous examination marks, internal assessment scores, and classroom participation.

The project demonstrates the complete Machine Learning workflow, including data collection, preprocessing, model training, testing, evaluation, and prediction.

## 🎯 Objectives

* Collect and preprocess educational datasets.
* Analyze factors affecting student academic performance.
* Build Machine Learning models for prediction.
* Compare different Machine Learning algorithms.
* Evaluate model performance using standard metrics.
* Gain practical experience in Artificial Intelligence and Machine Learning.

## 🛠️ Technologies Used

* **Programming Language:** Python
* **Machine Learning:** Scikit-learn
* **Data Processing:** Pandas, NumPy
* **Data Visualization:** Matplotlib
* **Deep Learning:** TensorFlow, Keras
* **Computer Vision:** OpenCV
* **Natural Language Processing:** NLTK

## 📊 Dataset Features

The project uses student-related academic information, including:

* Student ID
